# Sectors File Guide

## Purpose

`sectors.md` is the shared sector context board for market research. It stores compact, durable, cross-sector context that helps the Researcher understand which industries/themes matter and how current events affect tracked stocks.

It is not a daily news dump.

## Relationship to other files

- Use `daily_market_notes.jsonl` for daily market events and observations.
- Use `sectors.md` for sector baseline, current heat status, current narrative, tracked-stock relevance, and watch signals.
- Use stock profiles for stock-specific implications.
- Use prediction logs for falsifiable forecasts.

## Update rules

Update `sectors.md` only when one of these changes:

1. Sector heat status.
2. Current sector narrative.
3. Main drivers.
4. Confirming or contradicting signals.
5. Relevance to tracked stocks.
6. Watch factors.
7. Important policy/macro/geopolitical sensitivity.
8. New sector/theme becomes relevant.

Do not update for routine headlines, weak rumors, or repeated unchanged information.

## Sector entry format

Each sector should use this structure:

### Current status
### Why this sector moves
### Tracked stocks
### What matters
### What to ignore unless confirmed
### Confirming signals
### Contradicting signals
### Open questions
### Change log

## Writing style

- Prefer concise bullet points.
- Avoid long essays.
- Use trading-relevant language.
- Separate facts from interpretation.
- Label rumors clearly.
- Include dates for meaningful changes.
- Keep old change-log entries short.
