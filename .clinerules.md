# Cline Rules for OpenClaw Project
This is a repository for an OpenClaw project, which is a wrapper for allowing an LLM to run agentic operations on a given PC. If you need to learn more about OpenClaw, look to the refernce docs linked below. This repository is a project attempting to allow OpenClaw to work as an AI assistant for stock trading, with the goal of it being able to research stocks, current news, and analyze future movements.

## Local Reference Docs

- All mirrored OpenClaw docs are under `.openclaw/reference/docs.openclaw.ai/`
- Treat these files as **read-only reference material**. Do **not edit** unless explicitly refreshing or annotating.
- External Kimi/Moonshot docs are under `.openclaw/reference/external/` and should also be treated as **reference material**.
- Key reference directories for Cline lookup:
  - Feishu/Lark channels: `.openclaw/reference/docs.openclaw.ai/channels/feishu/`
  - Feishu plugin reference: `.openclaw/reference/docs.openclaw.ai/plugins/reference/feishu/`
  - Scheduled tasks / cron / automation docs: `.openclaw/reference/docs.openclaw.ai/automation/`
  - Multi-agent and sub-agent coordination docs: `.openclaw/reference/docs.openclaw.ai/subagents/`
  - Kimi API China endpoints: `.openclaw/reference/external/`

## Editable Workspace

- All your project files under `.openclaw/workspace/` and `.openclaw/workspace-*` (e.g., supervisor, researcher) are **editable**.
- `.json` files containing tracked stocks, paths, predictions, and memory logs can be read and written.
- `.md` files like `AGENTS.md`, `SOUL.md`, `IDENTITY.md`, `USER.md`, `standing_orders.md`, and `research_playbook.md` are editable, but the **bootstrap files** and mirrored reference docs are **not**.

## Special Rules

- When using uploaded files (like the one you just provided), always use the **uploaded file path** as an argument to a tool if the tool schema expects it.  
- Do **not** attempt to modify reference docs during normal editing or research tasks.
- Respect **read-only constraints**: only write to workspace files, shared files (like `tracked_stocks.json`), or explicitly mutable outputs.
- When working with Feishu or Kimi APIs, prefer official endpoints:
  - `https://api.moonshot.cn/v1` for Kimi from China
- For multi-agent coordination, consult sub-agent or supervisor instructions **before editing**.
